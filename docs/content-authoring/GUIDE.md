# 课程、课时与实验室集中填写操作指南

本轮使用真实后端保存、授权、文件访问和发布审批；预览站是独立合成验收库。正式教材、学生成绩、金币、徽章与人工原稿未导入或重置。文案与内置像素素材沿用现有版本，不恢复撤销的场景动效。

## 1. 入口与权限

- 管理员：课程管理 → 课程 → 课程总体填写 / 课时与内容 / 实验室填写。
- mentor：只可进入自己创建或被授予管理权的课程。同一套填写页与管理员共用；不能靠填写课程信息扩大学校、课程或学生账号管理权。
- 学员与授权仍单独管理。发布继续经过管理员审批；草稿保存、上传成功、实验试飞均不等于发布或完成学习。
- `?tab=intro`、`?tab=visual` 与旧编辑地址兼容到课程总体填写；课时选择保留真实 lessonId。页内定位只滚动本页。

## 2. 课程总体填写清单

| 内容 | 草稿要求与用途 | 学生显示 |
| --- | --- | --- |
| 课程名称 | 唯一必要的创建标识，最多120字 | 课程列表、地图与学习页标题 |
| 主题文字、适用学段、总课时 | 按需填写；学段缺省沿用兼容默认“初中” | 沿用原信息展示 |
| 课程简介 | 草稿可空；申请发布前必须有真实简介；故事背景写在这里 | 有内容才显示 |
| 核心问题、学习目标、材料准备 | 选填，各区按实际内容显示 | 未填不占空白教学区 |
| 图片与主题 | 单独保存图片用途和主题绑定 | 只作用当前课程 |
| 学生入口文案 | 原有模块开关、文案和同源编辑保留 | 依原配置显示 |
| 课程授权 | 独立的学员与授权页 | 不开放学生自行报名 |

**操作**：课程总体填写 → 填写课程信息 → 点击信息区“保存”；再按需填写图片与主题并“保存主题”。两者各有保存状态；同页不代表保存课程简介会提交图片或权限。草稿只在当前浏览器页面内保护，真实保存位置为服务器数据库；未保存内容不承诺跨设备、浏览器关闭或强制刷新恢复。

不再提供难度、独立故事输入。原 `difficulty`、`story_line` 保留兼容，旧故事可展开只读查看；不会自动拼入简介或覆盖人工文案。新课的旧数据库必填枚举由兼容默认值满足，不产生难度规则。

## 3. 图片用途与部分替换

| 用途 | 建议尺寸 | 行为 |
| --- | --- | --- |
| 课程封面 | 1280×720，16:9 | 课程目录缩略图，不是地图背景 |
| 桌面课程场景背景 | 1536×1024，16:9或3:2 | 课程空间底层，保持文字底板与对比度 |
| 手机背景 | 720×1280，9:16 | 窄屏背景；未填可沿用桌面图及预设 |
| 课程标识／侧栏装饰 | 透明PNG/WebP，256×256 | 完整显示，不拉伸 |
| 课时关卡图片 | 在本课时关卡区上传，建议透明PNG/WebP | 绑定真实lessonId，调节人物站位；不改学习顺序和权限 |
| 实验室封面 | 1280×720，16:9 | 本课程明确关联实验的目录图 |
| 实验室背景 | 1536×1024 | 本课程实验工作区底层，图表和结果接口不变 |

图片接受结构有效 PNG/JPEG/WebP，每张≤5MiB、≤1600万像素；透明图宜用PNG/WebP。只换封面：上传新封面 → 确认预览 → 保存主题。未改动的桌面图、手机图、标识绑定不会被清空。实验室的两张图片与课程背景独立。

上传失败时保留原图、所选文件和文字。重试沿用同一上传编号，避免重复资源；有失败图片时不能把设置误报保存完成，可重试或明确清除待上传选择。关卡图、资料及视频遵循原上传队列的状态与离开保护。

公共主题继续提供校园、蓝天、森林、海滩。专属远航宇宙只允许既有配置课程保留；新课程不能选择它。若服务器课程被公共主题或自定义背景覆盖，见 SERVER.md 中的定向预演工具，不按标题猜ID、不批量改所有课程。

## 4. 每个课时集中填写

进入“课时与内容”，选择一个课时。基本信息、关卡图、文章、回顾与提示、资料、视频和学生效果都在同页；可滚动或点击页内定位。只需要课时名称便可先存草稿。

- **选填介绍**：可写“10月21日14:00，科创教室，45分钟，张老师；请带记录本”等安排。时间、地点、时长、授课人不再分别输入；旧字段只读保留，不自动拼接，旧课表/安排兼容入口仍读取原值。
- 选择章节、地图顺序与模板；未分组课时保留。顺序仅用于地图，不新增跨课时门槛。
- 回顾、学习提示、实践说明、报告提示、现场记录介绍各按用途填写。选填内容未填时，学生同源展示隐藏整个对应区，维护模式保留可填写入口。
- “查看学生效果”切换展示；“编辑这里”直接改同一份草稿。结构化输入与原位输入即时同步，切换学习阶段或学生效果不自动保存、不清空待上传队列。
- 点击页底“保存当前课时草稿”把课时字段和文章块保存到服务器。已排队的资料、视频、图片仍需分别完成上传；正文保存不把未上传附件伪装成成功。
- 要离开、换课时或切路由时，未保存或待上传内容会提示；取消离开保留当前输入与File。上传中阻止静默卸载。强制刷新、关闭浏览器不保证恢复尚未上传的File，请先保存并上传。
- 保存失败保留输入；修订冲突点击“核对最新修订（保留草稿）”查看差异，仅接收新修订号，核对后主动保存。它可能覆盖同字段的另一位维护者改动，必须人工合并；不会自动把服务器正文替换到本页。

### 四模板及学习规则

| 模板 | 优先内容 | 发布与学生行为 |
| --- | --- | --- |
| 参观体验 | 本站文章、照片、回放、选填资料 | 有真实回顾/文章/课时视频才能申请；保持原只读体验，无自动通关、报告任务或金币 |
| 理论学习 | 概念、案例、知识卡片及习题 | 默认启用卡片前置；启用时须完整题目、答案和解析；报告与评审沿原规则 |
| 实践操作 | 实践步骤、材料、证据要求 | 新建默认可无卡片；仍须回顾、报告、评审和全部有效作品通过；实验单独明确关联 |
| 普通教学 | 原回顾→卡片练习→报告反思→评审 | 默认启用卡片；可显式关闭卡片前置，其他学习与奖励要求不取消 |

**本轮不提供任意关闭报告、评审或有效作品的开关。**旧教材未配置卡片开关时仍要求原卡片；学生开始学习时绑定的版本冻结该要求。修改不能让已绑定旧版本的学生跳过原条件。报告评分仍为原0–100整数；金币仍按现有结算和有效作品审核条件，不新增金额或签到规则。

### 发布与版本

1. 完成正文、已启用卡片及题目、任务和需要的文件；选择“已准备好，待发布审批”（参观保留原只读准备状态兼容）。
2. 保存正文，完成各上传队列并核对学生效果。
3. 本课时发布审批 → 提交管理员审批 → 填说明。
4. 管理员核对不可变提交快照，批准并正式发布；提交后再改草稿会使旧申请无法批准，须驳回并重新提交。
5. 正式课时可直接编辑和上传，无需关闭。保存只更新草稿，审批期间原正式版持续开放；管理员批准后新开始学生使用新版，已开始学生保留原报告、成绩、学习版本和答题机会。

## 5. 公众号文章导入、预览和修改

### 链接方式

参观模板 → 课堂文章 → 输入 `https://mp.weixin.qq.com/s/…` → 读取公众号正文和图片。只读文章与指定腾讯图片域，不运行网页。服务器会检查DNS公网地址、重定向、体积与超时。若反爬、验证码、压缩响应或网络拦截导致失败，用下面的本地包方式，不绕过访问保护。

### HTML＋图片方式（已用用户已有文章实际通过）

1. 用浏览器保存原文，提取正文为UTF-8 `article.html`，图片下载到 `images/`。
2. 推荐将唯一HTML放在包根目录，正文图片使用 `images/image-01.jpg` 这类安全相对路径。若正文仍引用公众号原图片URL，在根目录放 `image-map.json`，内容例如 `{"https://mmbiz.qpic.cn/原图片地址":"images/image-01.jpg"}`。
3. 打包唯一HTML、图片和可选映射JSON为ZIP。包内路径只能使用英文、数字、下划线、连字符与点；不含程序、CSS文件、脚本、嵌套包或绝对路径。也可单独上传不含图片的HTML。
4. 在“链接失败：导入HTML＋图片包”选文件，点击“导入本站文章草稿”。图片核验后存本站资源；正文先进入当前草稿，**仍须保存课时**。
5. 直接点击导入正文可视化改字，支持加粗、居中、左对齐；粘贴只保留文字。也可继续添加旧结构化段落、本站图片、附件并调整顺序。
6. 检查所有图片及提示，再保存课时。随后按发布审批流程向学生开放。

原“学生页面文字”同源预览也保留新导入图文块的可视化改字，保存仍写入同一真实课时对象，受当前修订与正式课时保护；日常集中填写优先使用课时工作区，以便同页共享草稿和队列。

**自动打包现有用户文章**（本机原材料只读）：

```powershell
node scripts/build-article-import-package.mjs --source-dir "C:/Users/shr/Desktop/nmg前端/deliverables/课时可视化维护与VR文章" --output "C:/临时目录/已有文章.zip"
```

输出文件必须不存在。该材料包含用户原图片，只私下交接；不在代码仓库中发布。当前9张图片的原位置保留，包括内容相同但位置不同的两张图片。

### 限制与失败判断

- ZIP≤20MiB，解压≤50MiB、≤200文件；单HTML输入≤2MiB、图片≤5MiB、一次最多40张且总计≤40MiB；并发最多3张。文章结构最多64层/20000节点；保存文章块总JSON≤250000字符，较长文章请拆分。
- 保留安全段落、标题、对齐、字号、颜色、内边距、简单边框与表格；文章样式在Shadow DOM隔离。
- 不保留全局CSS、外部字体、背景图、脚本、事件、SVG、画布、表单、交互组件、公众号专有视频/音频/iframe和复杂浮动布局。媒体被移除会显示“不完整媒体复制”警告；须另传本站视频，不能当成全媒体导入成功。
- 引用缺图时整次导入失败，未写入这次正文与图片；不能用空白图伪装成功。图片读取失败保留正文并提供重读。服务器再次清洗每次保存，不能通过可视化编辑绕过安全检查。
- 当前环境真实公众号链接DNS返回非公网地址，被保护拒绝；因此不能报告该链接在线抓取已通过。HTML＋9图导入、浏览器可视化改字、真实保存及学生读取已单独验证。

## 6. 视频、资料及原学习入口

视频提示和实际大小读取原上传策略：**支持MP4、WebM，单个视频最大1.5GB**（1500000000字节）。不提高资源附件原50MiB限制。视频在对应课时上传并绑定课时；课程共享视频不替代课时发布所需的有效视频。缺失文件、上传失败或未完成队列不会称为上传成功。

资料上传仍是资料，不会自动创建知识卡片；卡片与答案在原卡片编辑器管理。独立作品任务、评审、历史附件、报告、反馈、课程奖励和原导航保留；无作品任务时学生不显示空作品区。

## 7. 实验室集中填写

实验室填写页维护已有滑翔机的本课程名称、选填介绍、封面、背景和明确关联。上传图片后还需“保存实验室设置”。空介绍会隐藏，空图沿用内置素材。无关联不显示配套实验；独立实验室继续可用。课程级、课时级、阶段和卡片级关联沿用原入口，返回路径核验不变；不会自动提交作品或完成课时。

“自开发实验工具”“高级自定义课程模板”均明确暂未开放；不接收程序，不上传或执行脚本。物理引擎、参数、结果、旧关联和试飞记录未改动。
