# 文案怎么改

打开 [统一文案目录](copy-review/index.html)，选择页面，直接点虚线框里的字。点击「保存已修改 HTML」或「导出变化项 JSON」，把下载文件交回。文件保留原文、稳定 ID 和变化项，**下载文件尚未改网站**。每页列出实际角色、路由、组件区域与控件用途；公共字段在多个页面复用。

管理员也可在真实网站点击顶部「文案审阅」，再点当前页面的固定文字；同字来自多个位置时，弹窗让你确认 ID。编辑结果先保留在本次改稿，再导出。`/copy-review` 可以按页面或 ID 查找、点字编辑、保存或恢复**当前管理员账号在此浏览器**的草稿。恢复时检查旧基线，不覆盖更新后的文字。学生、普通教师、新媒体和执行导师没有系统文字编辑入口。

负责执行导师和管理员改教学文字时，进入对应课程的「可视化填写 / 学生效果预览」，点课程说明、课时、参观记录、卡片、练习或任务等区域，用已有表单保存。**这个保存按钮写真实后端**，沿用原授权和并发冲突检查。姓名、分数、学生已提交文字、身份、授权、URL 和评分字段不在系统改稿范围。空正式教材保持空。

开发者在仓库根目录校验交回文件：

```powershell
node scripts/page-copy.mjs '完整路径\改稿.html' '完整路径\另一页改稿.json'
# 看过变化与 issues 后，显式应用相同文件：
node scripts/page-copy.mjs '完整路径\改稿.html' '完整路径\另一页改稿.json' --apply
npm run build:teaching
```

同时支持 `page-copy-review-v1` 和既有 `fortune-review-v1`。只应用变化项；相同公共 ID 的不同改稿、重复 ID、未知范围、旧基线、未知字段或动态占位符丢失都会报错。必要动作、权限、失败及演示状态不能清空：单列该条问题，其余合法修改仍保留。可选辅助字可以关闭或清空，不补回默认字。HTML 用标准解析器提取纯文字与 JSON 基线，**不执行交回 HTML 的脚本**；尖括号、引号和脚本文字不当作代码执行。

原有 1092 条文案继续在 `frontend/src/content/uiCopy.jsx`；本轮补齐的其他角色/状态文案位于 `frontend/src/content/systemCopy.js`。两者由同一个导入工具校验并按来源写回，不把学生或课程数据硬编码进注册表。纯 JavaScript 模型使用不依赖 React 的显示适配器，原完成、授权、奖励和导出协议不变。

## 运势全部词库

打开 [今日运势全部词库](copy-review/今日运势全部词库.html)：宜 30 条、忌 30 条，加 12 条标题、等级、状态，共 72 个可改字段；不恢复已关闭的 `fortune.boundary`。

也可用文本编辑器修改 [60 条纯文字 JSON](运势60条-纯文字.json) 中的 `text`，保留 `id`、`baseText`、`baseEnabled`。新增一句建议时替换一个已有位置的 `text`，仍保持各 30 条；保留旧文件作为备份。不能追加第 31 条或随意换 ID。

```powershell
node scripts/fortune-library.mjs '完整路径\词库.json'
node scripts/fortune-library.mjs '完整路径\词库.json' --apply
npm run build:teaching
```

需要新副本时：`node scripts/fortune-library.mjs '新的完整路径\词库.json' --export`。它从真实注册表和 `shared/fortunePool.json` 导出，不从示例池另造一套。导入检查实际显示文字重复、空候选、关闭候选、数量及旧基线，只应用改动。

`shared/fortunePool.json` 是服务端实际使用的 30/30 受控 ID。词句更改仅需重新构建前端；修改算法或 ID 配置才需重启当前教学服务。相邻日宜组合与忌分别变化，宜避开昨日条目；有限词库长期正常轮换，不承诺永不重复。算法从 v2 升级为 v3 的当天展示会与旧版不同，v3 内同账号同日稳定。

## 明确的维护边界

- [逐页覆盖表](copy-review/coverage.json) 对照实际 `App.jsx`，共 46 个页面/视图文件，另有公共及只读映射。数量不代表每种后端返回数据都是可编辑系统文字。
- [494 条后端固定提示](copy-review/后端固定提示.html) 完整列出本轮抽取的控制器/中间件/服务固定 error、message、hint、reason 和异常文字。当前只读，部分原客户端用错误信息重新核验权限；改词需逐条语义核对后显式实施，不开放任意后端错误编辑 API。
- [74 处协议与固定身份片段](copy-review/协议与固定身份只读.html) 包括 CSV 导入/导出协议、错误匹配词、既定角色身份和原能力维度键，保留原值。动态通知正文、助手输出和学生作品不是系统文字；教学字段见 [维护映射](copy-review/教学字段.html)。
- 新 HTML 不覆盖原 31 份改稿、旧 28 页导出或历史冻结文件。生成器默认拒绝覆盖；刷新本轮自动文件前也会检测是否已有人工变化。有人工改稿时另建新目录。
