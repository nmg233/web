教学文字：使用原真实维护入口

管理员及负责执行导师显式进入课程「填写预览」，点对应区域填写并保存到真实后端。普通教师、学生、新媒体没有写权限；空正式教材保持空，不从本 HTML 导入示例教材。

这里显示字段与位置映射，不快照教学内容、成绩、学生提交或身份数据。动态示例「课时标题」「问题文字」仅解释位置。

课程说明

course.description / driving_question / story_line / materials_needed

课程详情 → 填写预览 → 点击课程说明

课时安排、参观记录与引导

lesson.title / description / start_at / end_at / location / instructor_id / duration / visit_moments / teaching_tip

填写预览 → 选择课时 → 点击课时或参观记录

知识卡片与练习

knowledge_cards.title/content；exercises.prompt/options/explanation

填写预览 → 知识卡片与习题 → 原可视化维护器

任务与报告开放问题

tasks.title/description；lesson.report_questions

填写预览 → 综合任务 / 报告引导

资源与回放

resource.title/description；lesson replay title

资源页签 / 原上传队列

徽章名称和描述

原真实课时徽章配置

通关徽章配置（不改通关判据）
