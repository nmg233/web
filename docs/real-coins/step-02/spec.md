# 真实金币接入规格（实施前）

基线 `1d9954df96b3dedf4369a3e2526271eb93d520a0`，初始工作区干净。仅本地教学环境；原仓库只读。

- 新增迁移022及新库schema：`student_coin_ledger` 是唯一金额事实源，余额为本人流水SUM，不另存可漂移余额；`student_coin_checkins` 保存账号+北京日期唯一的连签记录，并通过唯一流水外键关联。课时流水账号+课时唯一，签到流水账号+日期唯一。整数金额包含合法0，流水保留报告ID、版本、分数、标题与资格快照，不外键级联删除课时历史。
- 保留IndexedDB演示账户、120初值、旧签到及兑换记录/outbox。正式签到不再写演示账户，演示兑换/reset只操作独立演示余额。没有正式礼品。
- `/api/rewards/coins` GET只读账户摘要和服务端今日状态；`/coins/ledger?before=` 有限游标分页；`/coins/calendar?month=YYYY-MM` 单月；`/coins/checkin` POST空对象仅今天；`/coins/reconcile` POST空对象核对当前授权课程课时，不信任任何客户端金额/身份/评分。仅两分页接口放行各自明确参数，其余仍拒绝query。
- 抽取现有徽章学习任务判据，保留原徽章definition额外条件；金币不依赖徽章。最新报告approved且实际0–100整数，回顾、已发布卡片/必做练习、所有活跃作品任务最新版本均通过，内容ready，报名active课程published课时非cancelled；参观缺个人依据仍不可结算。0分也写一次结算；历史空分未结算可重试。
- SQLite IMMEDIATE事务内读取资格、服务端日期并写流水/签到；唯一索引最终防重，异常全回滚。按服务端Asia/Shanghai日期计算昨天连签、今日min(4+streak,10)，重复返回原流水。时间只允许内部依赖注入供隔离测试，不提供HTTP改时接口/生产环境时钟覆盖。
- 页面进入/学习真实状态变更、focus、visibility、online及午夜计时刷新；普通GET不发币，显式核对支持历史首次结算与重启恢复。请求序号/卸载abort/会话校验隔离账号与迟到响应。错误不显示猜测成功或演示余额；回读确认后允许安全重试。
- 新UI沿用原像素组件，“我的”签到区增加月历，顶部/课程内同一真实余额；真实明细有限分页，失效来源保留安全历史且不展示课时链接。旧演示区域明确标记独立余额。

## 迁移预检查、停止和恢复

实施前只读统计SQLite版本、版本号、表结构hash、approved空/非法分聚合数、完整性/FK及附件hash。现有工具短暂停止**对应教学进程**后一致备份至新`.local`目录，再恢复当前服务；源码新增迁移后先在隔离副本升级/重复执行/恢复到另一个新目录验证。迁移仅新表/索引，预期锁仅DDL事务，实际耗时记录；任何完整性、旧业务行/附件/配置差异或端口冲突立即停止接入并保留备份。不得seed/reset实际库，不停止全部Node，不动旧预览/公网。

接入前再次停止对应教学服务，迁移与构建验证后恢复原配置端口。代码回退不等于数据库回退：兼容新表可保留；出现新账本后禁止直接还原旧备份丢流水，需保留新库并修复前向代码。恢复演练只到独立新目录，不覆盖实际库。
