# 权限矩阵与撤销行为

|操作|管理员|获授权 academic_mentor|其他 mentor|teacher|
|---|---|---|---|---|
|课程列表、私有详情及维护|全部|仅授权课程|拒绝|沿用观察模块只读范围|
|新建自己的课程|允许|允许，自动建立显式初始关系|允许建自己的新课程|拒绝|
|课程管理授权/撤销/再授权|允许|拒绝|拒绝|拒绝|
|基础信息、课时、文章、卡片/习题、任务、实验关联|允许|授权课程内同权|拒绝|拒绝写入|
|回放上传/编辑/删除、资源与封面、关卡/主题图|允许|授权课程内同权，历史文件保护不变|拒绝|拒绝|
|课程范围系统文案和学生效果原位教材编辑|允许|仅授权课程/其课时|拒绝|拒绝|
|平台 global 文案、AI 设置/密钥、全局账号组织管理|允许|拒绝|拒绝|拒绝|
|报告/作品评审、反馈与相关学习档案|允许|只限所管课程及原合法学生范围|拒绝|原明确分配学生只读|
|课程报名|允许|课程授权 + 合法候选学生范围|拒绝|拒绝|
|异常移除报名|允许|只限所管课程|拒绝|拒绝|
|学校申请|审核|可提交自己的申请|可提交自己的申请|拒绝|
|批准、驳回、学校管理撤销|允许|拒绝|拒绝|拒绝|
|建班、建学生|原全局管理|仅获准学校；固定学生角色|未获学校授权则拒绝|拒绝|
|批量导入、任意角色/状态/迁校、删除学校|原全局管理|拒绝|拒绝|拒绝|
|真实个人金币领取/兑换|拒绝（仅管理）|拒绝|拒绝|拒绝|

课程关系以 `course_managers` 为唯一管理依据。`created_by` 是历史创建信息，`instructor_id` 是授课安排，后续修改这两者都不隐式授予权限。旧合法关系只迁一次；授权记录包含来源、授权/撤销人和时间、修订及审计。

撤销后无需退出旧会话：后端下一次请求即按当前关系拒绝，列表/详情/教材/主题图片/下载/签名播放/评审/档案/助手上下文均使用新策略。新作品、报告的通知收件人也按当前管理关系选择，不能因仍为创建者或授课人而收到新评审通知。

前端遇到单个 403/404 只触发课程详情重新核验。附件缺失而课程仍可管理时不卸载页面；核验拒绝则卸载课程私有内容，仅暂存当前浏览器亲自输入的文字，按账号与课程隔离，可导出核对。不会保留服务器读取的正文、自动重新提交或伪装保存成功。恢复授权后“重新检查课程授权”，再按本人输入核对填写；附件须重新选择。关闭页面前须自行保存导出的输入。

学校授权检查申请已批准、学校启用、管理关系有效、导师当前角色/状态/会话。角色、schoolId、classId、mentor_id 等注入字段被拒绝；班级归属在写入前重新核验。学校管理不授予跨课程学习档案；仅管理自己创建的学生基本账号和初始凭据。

课程报名移除继续保护作品、反思、评审、学习痕迹及教材绑定；不删除教学历史、不提供学生日常退课。管理员全平台账号维护及批量导入仍保持原权限。
