# 课程与课时填写字段清单

以下对应当前真实字段与接口，未引入任意表单、布局或学习规则设计器。

## 课程

|字段|要求与长度/格式|位置与保存含义|
|---|---|---|
|名称 title|创建必填，≤120字|新建/概览，真实课程对象|
|负责人 created_by|创建账号，原课程归属|概览显示，授权扩展第2步|
|学段 grade_level|创建必填，primary/junior/senior|新建；原课程编辑深链接|
|难度 difficulty|创建必填，basic/advanced/challenge|同上|
|主题 theme|选填，≤120字|教学主题，与视觉预设分开|
|简介 description|发布前检查，≤10000字|概览原位编辑|
|核心问题 driving_question|发布前检查，≤1000字|概览原位编辑|
|学习目标 learning_objectives|本步追加，≤10000字|概览真实保存；课程说明读取|
|故事 story_line、材料 materials_needed|选填，各≤10000字|概览；清空后学生隐藏|
|总课时 total_hours|选填，0–10000整数，0有效|新建/原课程编辑|
|封面、桌面/手机背景、标识|按需，PNG/JPEG/WebP≤5MB、≤1600万像素|主题页分用途上传、预览、显式保存|
|视觉预设 presentation_theme|campus/voyage|保留控件、字体与平台外层|
|背景不透明度 background_opacity|0–1|只应用背景层|
|实际课时、共享资料|真实列表与数量|不靠百分比推断完整度|

概览检查不增加原后端发布门槛。存量课程新增字段默认为空，不补造正式目标。

## 课时与教学内容

|字段/对象|要求与格式|维护入口|
|---|---|---|
|名称 title|必填，≤120字|新建模板、课时标题与安排|
|类型 presentation_type|learning/visit/theory/experiment|固定四模板，只决定引导与展示|
|顺序 sort_order|0–10000整数|课时安排；新课程同步路线|
|安排 start_at/end_at|选填，YYYY-MM-DDTHH:mm，结束不早于开始|课时安排|
|地点 location|选填，≤500字|课时安排|
|授课人 instructor_id|选填，现有可用执行导师|原权限，不扩展教师写入|
|时长 duration|选填，原规则正整数≤10000分钟|留空学生不显示；0不改成新规则允许值|
|关卡图、站位|图片同上；x/y 0.1–0.9|课时图片独立上传、保存|
|介绍 description、教学提示 teaching_tip|≤10000/2000字|原位/课时基本编辑|
|课堂回顾 review_content|选填≤10000字；原就绪检查可能要求回顾/视频/文章之一|原位区域|
|文章标题/链接|≤120字；HTTPS链接≤2000字|文章编辑；不接受网页源码|
|article_blocks|最多200块，总序列化长度≤250000字符；段落≤10000字|段落、本站当前课时图片/附件；保留原标点|
|参观说明 moments_note|选填≤10000字|参观原位区域|
|知识卡片及题目|沿用原标题/正文、题型、参考答案、解析、评价要点校验|同一 LessonContentEditor；分别草稿/发布|
|作品任务 tasks|真实独立任务对象；名称、要求、类型、附件要求、截止时间|新增独立任务/原位编辑；不合并报告和作品|
|报告与开放反思引导 report_guidance|≤10000字|原位保存；不改变报告必填/反思规则|
|实验引导 experiment_guidance|≤10000字|原位区域|
|实验关联|原glider关联数据：课程、课时、阶段、卡片、标签、启用|工作区实验关联；不默认附加|
|勋章|原课时定义|课程奖励兼容区；课程开关第3步|
|课时资料、图片、回放|真实文件/回放对象，自动当前课时绑定|课时内上传；共享文件另外上传|
|准备状态 content_state|preparing/ready|新建先准备中，核对后显式就绪|

## 文件

课程主题与关卡图只接受 PNG/JPEG/WebP。普通资料沿用上传策略：jpg/jpeg/png/gif/webp/pdf/doc/docx/ppt/pptx/txt/md/csv/xls/xlsx/mp4/webm/zip/obj/glb/gltf/stl，≤50MB，文本必须有效 UTF-8，表格验证真实结构。回放使用专用 MP4/WebM 入口，≤500MB，并填写视频简介。详情以课程共享资料页的真实格式表为准。

图片/文件上传完成并不等于文章已保存；文件引导卡不是知识卡片；课时准备中/卡片草稿/已发布/历史快照分别显示。移除引用保留历史文件。失败、冲突或权限变化不可伪造成功。
