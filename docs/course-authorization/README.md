## 旧能力 → 新位置

|能力|本轮位置与边界|
|---|---|
|课程创建者及旧授课导师的管理权限|一次性迁为显式关系；课程 → 学员与授权 → 授权审计可核对来源|
|新建课程|原创建入口；导师自建课程由服务端事务建立初始管理关系，管理员新建后进入学员与授权|
|管理授权/撤销/创建导师移交|课程 → 学员与授权；仅管理员操作，先授权接任人再撤销原人，历史创建者不改写|
|教材、原位预览、卡片练习、文章、回放、资料、主题与地图|沿用六页签同一对象编辑器；授权导师可维护本课程，原发布和冻结规则保留|
|历史兼容教材定向修复|原知识卡片高级编辑入口；授权导师可在本课程按原缺项/未结课约束操作，留审计，不重置作答|
|报名和异常移除|课程 → 学员与授权；导师候选限负责学生或已授权课程相关学生，移除仍须原因且无学习历史|
|报告/作品评审、逐题反馈、档案、导师统计与助手课程列表|原入口保留，统一使用显式关系；撤销后旧令牌不能绕过|
|学校申请|导师 → 账号与组织；申请、自己的审核状态、获准学校班级与本人创建的学生|
|学校审核/撤销学校管理|管理员 → 账号与组织 → 学校申请审核；工作台及通知链接直达对应申请|
|全平台建号、批次导入/恢复、凭据交付、学校迁移与角色管理|管理员原入口保留；没有开放给导师|
|课程奖励归属、可选勋章开关|尚未实施，仍属第 3 步；存量全局礼品/订单和金币规则保持|

课程授权与学校授权互相独立。教师继续只读观察；工作人员没有个人签到、金币领取或兑换资格。AI 启用状态未改变。
