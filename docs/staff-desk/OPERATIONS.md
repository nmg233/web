# 工作人员使用指南

## 管理员

| 常见任务 | 权限与路径 | 操作 |
|---|---|---|
| 查看真实待办 | 工作台 → 夹板待办 | 选择分类或「全部工作台事项」，点击对应行「去办理」；翻页保留在网址中。课程/学校数字进入对应分页列表。 |
| 授予已有学校 | 账号与组织 → 学校管理授权 | 点击「授予已有学校管理权」，选择现有有效学校、有效 mentor，填写原因并确认权限边界，保存。仅修改学校管理权。 |
| 撤销学校权 | 同页授权记录 | 确认来源是管理员直接授权还是学校申请批准，点击「撤销此项授权」，填写原因保存；若有另一个有效来源，仍须核对另一条记录。不会删除学校、课程或学生。 |
| 课程管理权 | 课程管理 → 对应课程 → 学员与授权 | 明确选择 mentor 并说明原因；学校管理权不会自动授予任意课程。 |
| 已有学生账号委托 | 账号与组织 → 学校办学账号 → 选择学校 | 使用现有账号委托操作，明确学生与 mentor；同校身份不代表可以查看全部学生。 |
| 建班、建号及教师观察 | 账号与组织 → 学校办学账号 | 选择学校；建班、建立学生/教师、交付临时凭据。教师观察必须指定学生和课程，教师无教学写权限。 |
| 外部 mentor 申请 | 账号与组织 → 申请会话与审核 | 按类型、状态筛选，打开申请，在原会话补充说明、查看附件、追问或审批。已有学校匹配仍用原审批校验，不重复建学校。 |
| 教材上传与发布 | 课程管理 → 课程 → 课时与内容 | 保存正文、上传完成和正式发布是不同操作。正式课时可直接编辑和上传到草稿，无需关闭；原正式版持续开放，课时新版本经管理员审批后生效。 |
| 评审与发放 | 工作台 → 对应待评/待发放对象 | 报告评审、作品版本和礼品发放保持原规则；不要用通知已读代替业务办结。 |
| 受理学生反馈 | 使用指南 → 处理反馈与通知 → 去办理 | 管理员进入 `/feedback/manage`，在原反馈会话受理及交接。 |

## mentor

1. 从工作台进入自己的待评报告、作品、反馈或申请回复；等待管理员审核的事项显示为进度，不伪装成可自行批准的待办。
2. 外部 mentor 通过「学校与账号 → 申请会话与审核」或「使用指南 → 申请学校」发起学校申请；填写用途和背景，后续补充、附件和审批都在同一会话。没有学校管理权也可按原规则建立课程草稿，但不能绕过上线学校或发布审批。
3. 获准后进入「学校与账号 → 学校办学账号」选择学校，在本校建班、建立本人负责的学生与教师。学校目录不开放其他学校；已有学生需要管理员明确委托。
4. 课程管理只能处理自己创建或被明确授予的课程。招生同时核验课程管理权、课程上线学校范围、学校管理权及学生账号范围；任何一项授权都不替代其他项。
5. 使用「课程管理 → 导入课程包」上传 ZIP、校验并预览写入清单后确认。确认回包失败先查询服务器结果；未确认不产生正式课程。恢复暂存时仍重新核验当前课程权限，不执行包内代码。
6. 进入课程六个工作区维护教材、资料、授权、视觉预览与奖励；关卡图上传只影响指定课时。关闭正式课时改稿后，提交管理员审核恢复，不直接开放给学生。
7. 「使用指南 → 处理反馈与通知 → 去办理」进入 `/mentor/feedback` 的授权课程学生反馈受理队列，在原反馈会话回复；向管理员交接保留内部说明与附件边界，学生只能看到公开内容。教师观察保持只读。

两种角色如需报告自己的问题，使用指南中单独的「提交个人反馈」（`/feedback/new`）；查看本人已提交记录仍用「账户菜单 → 我的反馈」（`/feedback`）。个人反馈列表与学生反馈受理队列是不同入口。

## 失败、重试与返回

- 学校授权保存失败：表单原因和选择仍保留，可重试。同一次未修改请求沿用编号，不重复写入或重复通知。
- 修订冲突：点击「核对最新修订（保留说明）」，核对当前状态再保存。不会覆盖另一个管理员的授权变更。
- 未保存编辑离开页面沿用原确认保护。切换组织页签会卸载隐藏页面；未保存内容须先保存或明确确认放弃。
- 工作台的「返回评审队列」保留原分类、页码；申请会话保留类型、状态与页码参数；顶部「返回上一页」沿浏览器历史返回。
- 学校/课程/账号撤权后，服务器重新核验访问；旧通知、附件或暂存课程包不能恢复越权访问。不会因为拒绝访问而删除原教学记录。
- 无待办、无课程、加载失败都有明确说明与重试。计数未知显示「—」，不把读取失败当作零项或完成。
- 收起侧栏后仍保留图标导航和可访问名称；键盘 Tab/Enter 可办理，手机用左上侧栏按钮展开。手机、长列表和放大阅读正常滚动。

## 自定义与素材

指南与菜单配置：`shared/staffWorkspace.json`；桌面布局：`frontend/src/pages/mentor/desk.css`；图标：`frontend/src/components/StaffPixelIcon.jsx`。人工教学正文和已有文案文件保持原维护方式，不通过修改这份指南替换教材。现有校园静态图片和字体随前端 public/build 发布，无额外素材导入。

北京时间电子钟使用本机时间按 Asia/Shanghai 时区显示，仅供工作台阅读；服务器签到、连续签到、金币与截止判定仍沿原时钟和业务接口执行。
