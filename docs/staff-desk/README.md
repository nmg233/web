## 实现范围

书桌包含北京时间电子钟、夹板待办、课程文件夹和常用操作。1440×900、1280×720 的测试数据首屏一屏显示；768×1024、390×844、360×640 及 720×450 阅读空间正常滚动。没有固定页面高度或裁掉长列表。工作台列表每页 5 条，课程文件夹最多 4 个；全部课程与全部事项保留完整列表入口。

待办读真实状态。报告、作品、反馈、申请回复、礼品发放、课时准备与发布审批各自保留状态；合并总数按对象去重。mentor 等待管理员审核的申请、发布进度可查看，但不计入本人应办理的待办。课程与学校数字可切换完整分页队列，「去办理」直达真实对象。评审详情返回时保留工作台分类、页码；课程返回保持原历史位置。教材编辑仍沿用原防丢稿保护。

统一申请入口保留原申请 ID、回复、附件、审批结果；旧 organization 的学校申请链接兼容到同一会话。组织页签卸载隐藏内容，避免重复申请界面和隐藏表单同时请求。后台通知与申请页、工作台只在页面可见时轮询；显示或重新聚焦后重新核验，避免请求重叠。

管理员可在「账号与组织 → 学校管理授权」授予已有学校。没有伪造已批准学校申请。授权带原因、操作人、修订和审计记录；并发与重试使用事务、请求编号及修订检查。学校权、课程权、既有学生账号权分别维护。外部 mentor 的学校申请流程继续保留。

## 启动与复验

在仓库根目录、已安装锁文件对应依赖的环境中：

```powershell
npm run lint --prefix frontend
npm test --prefix frontend
npm run build --prefix frontend -- --outDir ../build/staff-desk
node scripts/preview-staff-desk.mjs
```

首次运行预览脚本只创建隔离合成库；重启复用该预览库，不重建已有库。端口为 API 3220、页面 4220；端口占用时停止，不覆盖已有服务。脚本不接受教学库路径，私有配置只写 `.local`，不提交。

浏览器回归使用临时数据库与真实 Edge：

```powershell
$env:PBL_REGRESSION_DIST='build/staff-desk'
node --test --test-concurrency=1 tests/staff-desk.browser.test.js tests/staff-campus.states.browser.test.js tests/mentor-step2.browser.test.js tests/mentor-step3.browser.test.js
```
