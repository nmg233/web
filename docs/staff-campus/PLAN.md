# admin / mentor 校园视觉统一

基线：已合并PR48的82b021bfbb23a31da21190e302f703fc747001ee。分支feat/staff-campus-visual；只提交自己的web-frontend-test，用户验收前不提上游PR、不部署正式站。

## 范围

沿用学生端已验收的北航校园像素体系，重新制作横/竖校园场景和统一24网格装饰图标。admin与academic_mentor共用校园外壳、侧栏、顶部、卡片、边框、表单、表格、列表、标签、上传、通知、弹窗、抽屉和交互反馈。学生、普通teacher、新媒体及课程内部独立场景保持原作用域；学生效果预览仍由原同源组件显示。

不变项：五项导航数量/顺序/路径、按钮文案与操作、表单字段与数据绑定、权限、API、上传与保存、教学版本、金币与奖励、数据库及迁移。仅可调整页内对齐、间距、栅格和阅读层，不新增入口或改变业务流程。

## 视觉

- 原创奶油白校园建筑、蓝玻璃、银杏与航空教育线索；不把宇宙/某课程主题当管理端通用装饰。
- 寒蝉团圆体、海军蓝文字、青绿主操作、少量金色、硬边与阶梯角。背景放在场景层，阅读层独立遮罩，不给整段内容调透明度。
- 表单、表格和教材保持高对比、易分组；图案主要位于侧栏、内容边缘及标题装饰，不能穿过正文。
- 原生SVG图标替换外壳与工作台的普通线图/emoji装饰，图标无额外按钮或可访问文本，不改变已有键位。
- 可点击控件有hover、press、focus；disabled/loading不弹跳，输入框和滑条不整体缩放，reduced-motion保留颜色与焦点而取消位移。

## 验收

admin和mentor覆盖工作台、课程列表/创建/六页签、教学与成长、学校与账号/申请/观察、使用指引、反馈/通知、平台设置/系统文案/AI配置等现有页面。主要页面做1440/768/390，另查1920、360和横屏；弹窗、上传、失败/空状态、折叠图标、返回、焦点、减少运动和角色切换均检查。

使用独立合成环境和随机私有凭据，旧4187及教学数据不写入。保留前后对照、素材母版/提示词/清单和真实截图，报告真实通过项和未验项。文案及权限规则不因视觉修改重新设计。
