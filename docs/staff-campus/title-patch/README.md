## 原因与修复

上轮校园CSS将动态顶栏高度同时设到工作区栏和课程标题栏。课程标题已在原`maintenance.css`中设为`position:relative;top:auto`；新增规则使其相对下移，后续信息卡的正常文档流位置没有跟着移动，形成遮挡。

本轮真实内置Browser复现：导师课程#91001，390×844、scrollY=0，主顶栏119px；标题`position:relative;top:119px`、实际top254px，标题bottom416.80px，信息卡top313.80px，重叠103px。桌面隔离自动测试也复现两角色75px相对偏移。

**产品只改一条选择器**：`staff-campus.css`的动态`top`仅匹配`.course-workspace-context`，不再匹配`.course-detail-header`。标题继续使用原正常流规则，保持原边框、内容、按钮、返回和状态操作；没有增加第二层吸顶，没有隐藏信息卡。实际高度测量及工作区吸顶逻辑保留。

修复后390手机：标题computed top为0px，标题top135px、bottom297.80px，信息卡top313.80px，间距16px、重叠0。滚动后工作区栏的实际top紧贴真实顶栏bottom；不是只核对computed top数值。
