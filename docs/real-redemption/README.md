# 真实礼品兑换验收入口

本轮在 `integration/real-gift-redemption` 实现；基线为 `17099fe`。保留教学数据、人工文案、签到及课时奖励规则和像素界面。只运行本机环境，不切换公网。

## 页面与指南

- 本机入口：http://127.0.0.1:4184 。管理员侧栏「奖励管理」进入 `/reward-management`；学生成长档案 `/me` 兑换实物、查看所有兑换记录，`/me/badges` 兑换数字徽章并查看徽章墙。
- [截图验收入口](index.html)：管理员上传、预览、发放，学生实物兑换、跨设备订单、真实徽章和三种尺寸。
- [管理员操作指南](管理员操作指南.md)：教材不受影响；礼品录入、图片上传、保存、上下架、库存、学生预览、线下发放及通知恢复。
- [实际验证记录](验证记录.md)：测试范围、命令、结果和真实环境保护检查。
- [迁移与上游整合说明](迁移与上游整合说明.md)：编号兼容升级、备份恢复、数据边界及尚存运行时整合冲突。
- [接口及数据约定](接口及数据约定.md)；[可用于 PR 的说明](PR描述.md)。

正式教学库没有预置礼品、价格或订单，管理员看到空状态。截图中名称带「验收／测试」的礼品全部来自隔离数据库；使用真实服务、真实上传、真实事务和浏览器交互，不是前端模拟。旧演示存储和事件保留独立，正式入口不再使用演示余额或演示兑换。

## 启动与复验

已有持久环境直接运行，不重新初始化：

```powershell
npm run build:teaching
npm run teaching -- start
```

已有实例无需重复启动。停止用 `npm run teaching -- stop`。数据位于私有 `.local/teaching`；普通启动不 seed。不同数据库类型的隔离复验及备份恢复命令见验证记录。截图及日志在忽略提交的 `evidence/` 内，本地验收可直接打开；他人检出分支后运行测试可重新生成，不携带真实数据库、密钥或上传文件进入 Git。

本轮没有增加取消、退款、撤销徽章、自动物流或其他奖励规则。上游全部运行时没有整体合并，明确边界见整合说明。实现、回归及本地迁移完成后停止，等待复核。
