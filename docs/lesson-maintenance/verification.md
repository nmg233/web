## 首次失败与修复过程

- 旧 WAL 备份被校验发现未登记 SHM 文件：只对新生成的备份副本转 DELETE 日志再生成 SHA；源库 WAL 不改。新增未 checkpoint 行备份与恢复测试通过。
- 存量关卡编辑时旧 preset 被新校验拒绝：允许原课时保留未变化 preset，拒绝任意换成其他旧 preset；真实普通字段编辑复验通过。
- 上传/确认按钮的 loading 图标影响可访问名称：显式名称及 PixelButton 文本推导修复，原生鼠标失败重试通过；未用 DOM 文本替换或私有 React 属性。
- 管理员课时预览用 MemoryRouter 时原 window 路径守卫不匹配：预览独立逻辑路由守卫，学生原守卫保留。真实教材标题与说明点击复验通过。
- 最终全套首次在沙箱遇到本地端口 EACCES；获准环境复验时，挂起测试占用 4424 导致 EADDRINUSE。只停止核实属于本轮的测试进程后再跑，未停止原教学服务。
- 后端并行测试发生 Node 消息反序列化错误，串行同一套 380 项全部通过；未将运行器失败记作业务通过。
- 原学习浏览器脚本依据旧界面选择器、旧无必做练习的徽章 fixture：按当前上游上传队列、可访问 tabpanel 和真实完成前置更新测试，未改产品业务规则。

## 文案覆盖与实际限制

清单为 29 个页面组、127 个学生/公共源文件、2139 个已注册系统文案 ID。`pages.json` 列页面，`coverage.json` 列来源、绑定和保存位置；817 个内联与 364 个属性标记支持对应屏幕点选。清单中的运行时引用不等于所有状态当前都在屏幕上；未触发的空、错、弹窗或没有个人记录的详情可通过文字清单检索编辑。管理员预览不借用学生身份，不伪造姓名、分数、金币或已提交答案；这些个人记录保持为空或原业务数据，不能通过 UI 文案覆盖。
