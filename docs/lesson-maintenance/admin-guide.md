# 管理员操作指南

以下操作要求部署本分支并完成 1027/1028。只看旧版页面或仅拷贝图片，不能得到新维护界面。管理员可管理全部课程；执行导师仅维护自己的/受邀课程；普通教师保持只读，视频上传仍只允许管理员。学生文案管理仅管理员。

## 进入具体课时

课程管理 → 课程详情 →「课程内容维护」→ 选择真实课时 →「进入本课时维护工作区」。可直接访问 `/courses/课程ID?tab=maintenance&lesson=课时ID`。标题、课时 ID 和「本课时内容与开放状态」应先核对。

这里会列出知识卡片总数/已发布/草稿、引导卡文件数、教材快照、绑定学生数及就绪检查。管理数、学生可读数和当前解锁数不是同一个值。需要针对某个学生核对时，使用只读预检的 `--student-id`；不要用管理员预览推断学生已完成的步骤。

## 填写、上传与保存

1. 「课时标题与安排」维护名称、介绍、上课时间、地点、授课人、时长和关卡图。缺失值按原空状态显示；真实标题不在系统文案管理里改。
2. 回顾/文章编辑区使用既有可视化正文编辑器。文字、图片、文件块和合法 HTTPS 外链分别保存为真实课时字段/资源；预览读取同一份教学数据，不向学生答题/报告接口写入。
3. 「知识卡片与习题」进入本课时的原编辑器，逐卡填写正文、题目、选项、答案及详解，保存草稿并逐项发布。上传 PDF/guide_card 文件只是资料，不会自动生成 25 张练习卡片。已有卡片应编辑原 ID，不删除重建。
4. 本课时资料、回放、任务、报告与反思引导、实验关联都在当前课时维护。上传前核对所属课时；「课程共享资料」是独立区域，留空课时的共享资料不能冒充本课时内容。回放须管理员上传并绑定正确课时、填写简介。
5. 上传队列完成后保存对应教材表单。文件成功上传不等于表单保存完成；保存失败保留本次输入和选择，按照错误提示重试。使用「重新读取」前先保存/取消草稿；并发冲突先核对最新内容，不强行覆盖。
6. 页面内未保存表单、正文、上传处理或新增课时会触发离开保护。不要把浏览器关闭前的临时选择当成服务器草稿；服务器已保存内容才能在刷新/重登后读取。既有正文草稿与队列恢复机制继续使用原账号/课时隔离规则。

## 就绪、发布和教材版本

preparing 会向学生显示准确的准备状态及已发布内容的只读预览。草稿卡片仍隐藏，学习操作不可执行。管理员先处理诊断中的正文/回放、卡片与习题问题，再点击「核对后标记本课时已准备」，阅读确认框后保存。这个按钮只改当前课时的准备状态，不发布草稿、不完成学生回顾、不授予金币或通关。

ready 后学生仍须完成原回顾，按顺序完成卡片，再进入报告/反思和评审。若已有学生绑定旧教材，后续卡片修改不会自动重写历史。诊断区会提示绑定数量；按原补学/版本流程处理，不能通过删除绑定记录、重写快照或清空学生作答“同步”教材。

## 关卡图

创建课时：课程详情 →「课时安排」→「添加课时」。编辑课时：当前维护工作区 →「课时标题与安排」。两者都有「关卡图片」。

1. 选择 PNG/JPEG/WebP，最大 5MB、1600 万像素，服务端校验真实文件结构。建议透明 PNG/WebP。SVG、伪装图片和越界站位会被拒绝。
2. 先看浅底、深底和独立宇航员预览，点击「上传并保留到当前表单」，再保存课时。未上传的选择会阻止误保存；上传失败不丢选择，重试沿用幂等编号。
3. 横/纵站位使用 0.1–0.9 的标准化坐标，预览与真实地图用同一组件。图片 contain 保持比例，宇航员不在图里。存量前三关保持原题材图/站位。
4. 「移除并恢复岩石默认图」后保存，地图才改用默认图。旧资产不自动删除，避免误删引用和破坏备份。新课时不上传也可以创建。
5. 图案跟随 lessonId，改排序不丢关联。404/坏图只回落岩石并提示，不卸载学习页；新图替换后清除旧失败状态。权限失效仍按课程权限核验，不继续显示失效数据。

本轮提供的是第四课时制作台候选，不自动绑定第 4 个数组元素。只有核对真实课程/课时 ID、标题及哈希后才可在 UI 或计划脚本绑定。

## 学生端文案管理

管理员侧栏 →「学生端文案管理」。选择页面、课程、课时与作用范围：全局、单课程或单课时；覆盖优先级为课时 → 课程 → 全局 → 原人工定稿。

课程覆盖用于实际课程路径，课时覆盖用于实际课时学习路径。登录、平台首页、我的等页面使用全局；切换到不含原上下文的页面时会提示先保存，并调整可选范围。仅选择预览课程不会把平台页变成课程页，也不会扩大学生实际读取范围。

1. 默认「点字编辑」开启。在与学生同源的受控页面中点文字，会打开稳定文案 ID 对话框；按钮/占位等复合属性可在对话框下拉选择。不会触发兑换、提交或作答。
2. 输入改稿，保留 `{slot0}` 等动态占位符，确认后只是当前页面未保存输入。点击「保存服务器草稿」，再查看预览；学生尚不可见。
3. 「发布已保存草稿」并确认后，学生已打开页面最多 25 秒或重新聚焦生效，新会话直接读取发布版。无需改 JSX、重构建或清缓存。读取失败使用原定稿并按授权重验，不缓存另一账号/课程覆盖。
4. 可选说明可清空/隐藏，发布后真正消失，不被 fallback 补回。必要按钮不可删除。输入及数据库保留标点；完整句子只在显示层省略末尾句号，不处理正文/URL/代码。
5. 尚未触发的加载、空、失败、退回、弹窗和 toast 文案可用右侧清单搜索 ID/原文编辑；不能把“源文件存在绑定”当成当前全部可点选。取消点字模式可浏览本地步骤和弹窗，但所有业务写入仍禁止。
6. 并发保存返回 409 时，当前输入保留。点击「核对最新版本（保留输入）」逐项选择我的/服务器值，确认后再显式保存。恢复历史/恢复默认都先生成草稿，核对后再发布。
7. 旧 `page-copy-review-v1` JSON 通过「导入原文案审阅JSON」预览差异。基线变化、已有人工草稿且无可信基线的条目列为冲突，不自动覆盖。服务器导入也只存草稿。

真实课程/课时标题、卡片正文、资料说明等点选会进入原教学维护入口；个人姓名、成绩、余额、学生答案、报告和订单值不能替换成任意系统文案。预览始终保留管理员身份，个人记录为空、没有模拟的真实奖励或学生历史。详情页没有个人数据时呈现相应空/错误状态，编辑文字需用清单或对应真实状态；AI 预览为关闭能力的现状，不作为上线 AI。

`content/student-copy/pages.json` 列出页面入口，`coverage.json` 列出每个源文件的文字/属性标记与运行时引用，`catalog.json` 为可检索 ID。新页面或后续新增文字要显式绑定后重新运行 `node scripts/lesson-maintenance/audit-copy.cjs`，不能靠 DOM 搜索匹配。
