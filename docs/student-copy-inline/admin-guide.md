# 管理员操作指南

## 进入学生真实效果预览

以管理员登录，点击侧栏或顶部的 **编辑学生页面文字**。选择学生页面；课程页再选课程，课时页再选课时。这里复用学生实际组件和布局，但始终保持管理员身份，不会借用真实学生提交、兑换或答题。

默认点字编辑。需要打开页内弹窗或切换学习阶段时，暂时取消勾选“点字编辑”，进入对应位置后再勾选，然后点文字。学生业务写入始终禁止。

## 系统标题、按钮、导航与提示

1. 点显示位置的文字，直接在弹窗修改。
2. 核对影响范围：全部学生、当前课程或当前课时。没有对应课程/课时的页面不能选择无关范围。
3. 点 **保存并同步学生端**。成功后服务器立即保存发布版；已打开学生页最多 25 秒自动读取，或重新聚焦时读取。不需要导出 JSON、改源码或重新构建。

如果这段文字已有未发布人工草稿，会列出当前发布与历史草稿；必须勾选确认后才能同步。只同步这次所选文字，其他历史草稿仍保留且不会顺带发布。

找不到的空态、错误、加载或尚未打开的弹窗文字，可用右侧“当前页面文字”分类检索；切到“所有页面及公共组件”可查共用导航和其他状态。不需要理解文案 ID。高级区域保留离线审阅、JSON 交换、草稿和发布历史，日常修改无需使用它们。

可选说明可清空并关闭显示；必要按钮和动态占位符不能删除。系统完整句子只在显示层省略末尾句号，存储原文不变。

## 真实课程、文章与教材字段

点课程/课时标题、介绍、课堂回顾、文章、卡片或资料说明，在当前预览旁打开教学编辑侧栏。空内容或尚未出现的阶段，可以用预览上方“当前页面教学字段”入口。它们保存到真实教材对象，不会保存成全局 UI 文案。

- 课程名称与介绍：在侧栏填写后保存，学生重新读取课程页面即可看到；课程发布/归档状态不改变。
- 课时说明、回顾、报告与反思引导：在真实对应字段编辑，不改变就绪或完成状态。
- 知识卡片：保留卡片 ID、排序、习题和状态。草稿不会因普通保存自动公开；确需发布时，核对后勾选“保存时仅发布这一张卡片”。不会发布其他卡片。
- 资料和任务：选择原有对象，修改名称/说明，原附件、提交条件和关联保持不变。当前没有对象时显示不可编辑状态，不凭空创建正式内容。

教学内容沿用原教材版本机制：准备中的课时只读展示适用内容；就绪后尚未绑定教材的新学生进入时使用当前教材，已经绑定的学生继续使用原快照。历史答案、报告和评分依据不覆盖。保存结果会说明这一范围，不能把它理解为强制刷新所有已绑定学生。原教材维护与历史补学流程仍保留，本工具不自动执行它们。

## 文章、图片与附件

在“课堂文章”侧栏编辑标题、原文 HTTPS 链接和段落。正文保留原标点、网址和代码文字，不套系统标签的去句号规则。

使用原上传队列选择当前课时图片或附件，再点“上传待处理文件”。上传成功后自动插入对应图片/文件块；也可插入当前课时已有图片、附件，编辑说明、上下移动或移除引用。移除引用不会删除原上传文件。最后点 **保存并同步学生端**，上传本身不等于正文已保存。

只能引用当前课程、当前课时的安全资源；不接受任意 HTML、脚本或外部嵌入。图片及文件下载仍走原授权接口。图片/附件读取失败只在对应位置提示。

## 失败、冲突与恢复

- 网络或权限错误：保留当前输入，修复问题后再保存；权限失效不会放行写入。
- 修订冲突：点“核对服务器版本”或“核对最新教材”，比较服务器内容与当前输入；确认只接收新修订号，之后自行决定如何保存，不自动覆盖。
- 已保存但回读失败：界面明确提示保存成功。只点“重新读取”，不要重复创建或重新上传。
- 上传失败：保留队列与文件选择，用原队列重试。切换对象、关闭侧栏和离开页面前会检查未保存输入或正在上传状态。

姓名、登录账号、真实金币、得分，以及学生自己的答案、报告、作品、反思和订单等实际业务值不能通过文字工具修改。姓名/金币点选会显示只读说明；旁边的标签和提示可以编辑。普通教师没有本工具写权限，执行导师既有课程维护权限不扩大。
