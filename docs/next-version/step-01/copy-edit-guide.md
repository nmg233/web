# 本步文案改稿

新增必要文案在 uiCopy.jsx 的 next.* 项。既有稳定 ID、用户文字和 enabled 状态原样保留；旧冻结 HTML/JSON 不重建。

[新文案编辑器](copy-review.html) 可修改系统文字，关闭允许隐藏的可选项，然后保存已修改 HTML 或导出修改 JSON。交回完整文件路径后再核对合并；编辑器不会写入网站或课程数据库。

必要按钮/权限/保存状态不可关闭。JSX 与 HTML 同时改且有冲突时不能自动覆盖。文件生成后再次运行导出脚本会拒绝覆盖人工改稿。

教师标题/正文/精彩瞬间/文章/资料说明通过真实维护页面保存，不是系统改稿。本版只导出系统 registry，不把旧合成教材作为正式教学文案。
