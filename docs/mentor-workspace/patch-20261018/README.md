## 权限恢复与历史例外

新三元授权的来源为mentor、admin或admin_assignment时，teacher/student/快照学校必须一致。mentor派生来源还需授予人当前有效、获批学校管理、课程管理和组织账号来源。委托撤销不会删除grant历史；仍有本人创建来源时不误伤；明确撤销的grant不会因组织关系恢复而复活。

`legacy_teacher_id`仅保留原迁移冻结的学生/课程以及既有历史跨校例外，仍需原teacher_id关联、学生学校快照、有效账号和原grant；不自动扩展新课。迁校旧入口同样要求先交接teacher_id及active三元职责。管理员独立授权与mentor委托分开，撤mentor不能误撤管理员授予。

## PDF的实际边界

本轮没有引入可可靠解析/净化全部PDF对象与流的组件，所以选择明确拒绝课程包PDF，而非补几个动作名称正则。普通正常PDF也不能随v1包导入；可以用可信工具转换为结构化文字与本站图片，或人工核对后经原课时资料入口单独补传。原资料/反馈附件入口保持既有策略，不因此宣称具备PDF活动扫描。历史已导入文件不删除、不清空引用；含PDF的旧暂存包需转换后重新校验，修改内容应升包/内容版本。

课程包仍支持UTF-8 TXT/MD/CSV、结构有效本站图片及既有教学对象。当前网页提示、格式表、只读指南和离线工具一致；没有改动实际MD测试样包。450字节复核样本只证明旧校验器接受禁止动作，不证明发生执行。
