# 高级课程开发设计（本轮未部署、不运行）

现状：管理员可记录mentor×课程的开发方案准备资格，含用途、审核、授予者、期限、撤销和审计；导师可提交开发申请并对话。资格不授予课程或学校权，不解锁代码运行。当前主站没有动态导入包代码、任意安装、SQL或命令入口。

## 模块契约

- 关卡展示可配置，但真实lessonId、可访问性、教材版本、学习阶段、提交与完成由主站计算；展示层不能以排序另设门槛。
- 实验只用已注册能力；结果与作品提交分开，不直接发金币/勋章。后端计算仅由经管理员审核的独立服务承担。
- 成长档案允许选展示，不能改原报告、作品版本、评审、反思、钱包和历史。数据包不替换主导航、登录、按钮、账号空间和核心教学契约。

## 未来运行方案，需另立项审查

1. 独立来源与独立部署前端，不与主站同源；域名、版本、静态资源哈希及负责人登记。不以普通iframe、Node vm或隐藏菜单当安全保证。
2. 版本化消息契约例如capability-v1。消息带协议版本、固定类型、一次性会话标识和请求ID；接收时精确校验event.origin、event.source、结构、大小、速率及当前授权。禁止通配origin、任意URL/脚本或跨课程ID透传。
3. 数据按最小化能力提供当前授权课时的必要描述和随机会话标识；不传主站登录令牌、密钥、完整学生名册、成绩/钱包。主站代理经白名单与对象授权的能力API，每次核验权限，到期/撤课立即失效。
4. 资源采用明确CSP、sandbox属性、隔离存储、网络白名单、大小/CPU/频率限额和拒绝外网默认策略；下载/导航/剪贴板等能力逐项审核，不以iframe属性代替独立安全评估。
5. 每版本静态扫描、人工内容/交互/数据审核及隔离测试后才登记；不可静默替换已审版本。保留停用开关、超时、失败降级、日志和上一版回退。停用时主站继续可学习，未确认结果不写完成。
6. 若需计算服务，独立最小权限进程/容器与受限API；管理员负责部署，固定依赖镜像与资源网络限制。禁止主站运行包内命令、SQL、安装依赖或迁移；不暴露服务器文件系统和数据库凭据。

这份方案不表示环境已具备；上线前须另行实现、威胁建模、安全审核及运维验收。本轮交付不包含这套执行环境，也不切换公网。
