# 素材来源、用途与验收

本轮参考自有像素技能的 preview.html、校园选课图、理论关卡同类参照；参照实际打开并按网页真实尺寸检查，复制只用于来源记录，未修改原件。详细原路径与逐次提示词见generation.json。未引入外部网页画作。

先生成蓝天、森林、海滩各一场景/一节点，在网页960场景、220节点及站位做对照，再完成批量。三个主题各封面、桌面、独立手机、真透明标识、观察/制作/分享节点，共21；校园补三枚通用节点，总24母版。校园背景/封面复用原redesign-v2，不把复用计为原创。

所有母版由实际内置image_gen产生，生成工具记录齐全；模型无法核实为null。一次海滩场景请求连接中断，重试后实际落盘，未伪造失败结果，未用付费API。

发布文件为无损WebP：背景480/960/1536、节点192/384、标识96/192/384，共60。只做等比nearest尺寸衍生，尺寸舍入≤1像素，保留alpha，无重绘、背景删除、内容裁切或色彩修改。侧栏是主场景的CSS居中裁切，课程封面用独立cover；手机用独立mobile；不是把裁切称多件原创。

用途由content/course-themes/registry.json受控映射：cover用于课程卡片，desktop用于课程地图/阅读场景及侧栏裁切，mobile用于窄屏场景，mark用于课程标识，node1/2/3用于课时明确选择的关卡。复用背景的实验目录/成果区仍盖奶油稳定阅读层，不新增独立母版声明。

实际验证：24母版、60发布文件逐个PIL解码、尺寸与SHA256核对；15件透明母版均含真alpha；像素skill audit_assets.py校验24件通过。角色与关卡独立，非voyage主题不自动放太空人；真实四主题地图截图见上一层index。

内部验收不代表用户视觉通过。本轮交付后停止，等待总验收。
