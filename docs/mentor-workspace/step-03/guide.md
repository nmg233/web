# 导师办课、填写、上传、保存与发布操作指南

适用于本轮 mentor-workspace-v1。管理员可完成同样操作，记录真实操作者；教师为明确学生×课程只读观察者，学生只进入自己有效报名且已发布的课程。先完成强制改密。开发资格与回复都不自动授予办学权限。

## 1. 从学校申请到学生学习

1. 导师工作台 → 学校与账号 → 学校申请，填学校名称、地区、用途和联系方式。申请可往返说明，管理员另行批准/驳回。同名学校需人工核对，不以文字相同自动合并。
2. 批准前可创建课程草稿、填写教材；批准后才能在获准学校建班、建学生和teacher账号。固定角色不可自行升权；账号仅由创建者或管理员明确委托者维护，同校不自动获得他人学生。
3. 建班后建学生/teacher，初始凭据私下交付。首次登录须改密；已改密或停用凭据不可重新导出。批量操作失败按实际结果修正，不重复创建成功项。
4. 新建课程 → 填名称、学段、难度 → 选四公共主题 → 保存草稿。在课程“学员与授权”明确选获准学校、填写原因并保存；学生还需单独报名，不自动全校招生。导师须同时有课程管理、学校管理和本人/委托学生账号权限。
5. 填教材、预览后分别发布课程、设课时就绪、发布卡片。课程只发布不代表课时/卡片已开放；填完一个字段不代表全部教学内容齐备。学校范围缩小对旧报名须管理员明确核对，不删除历史。
6. 组织账号 → 观察范围，逐条选择teacher、学生、课程并说明原因。教师只能看交集，不自动看全班或全校；撤权/停用实时生效。
7. 学生回顾→卡片练习→报告与反思→原有作品任务→导师评审，金币与可选勋章沿原规则核对。参观课暂无个人通关记录时不能擅自发奖励。实验不自动提交作品或完成课时。

## 2. 逐项填写、上传和保存

|位置|填写检查|操作与空值|
|---|---|---|
|课程基础|名称、学段、难度；选填说明、驱动问题、目标、故事、材料|保存课程信息；未填选填字段不编造给学生|
|课时安排|真实课时标题、顺序、四模板、时长及实际时间/地点/授课人|未提供的安排显示空状态；主题不决定模板|
|回顾与提示|回顾正文、教学提示、报告/实验/反思引导|保存至服务器；不把提示当学生答案|
|文章|标题，段落/本站图片/资料块；合法HTTPS链接|先上传本站资料，再插入对应块；同课时引用，不能粘任意生产ID|
|卡片与题目|标题、正文、选填摘要/要点/误区/示例、必修和时长；原五题型、答案/解析/开放题参考|先保存草稿、逐项核对，再单独发布；题型语义沿原校验|
|作品任务|标题、说明、类型、附件要求和实际截止时间|保存任务；作品和报告保持不同对象、版本与评审|
|资料/回放|真实文件、标题、用途和所属课时|等待上传成功后核对保存；普通附件ZIP不自动成为课程包；视频使用回放/视频专用入口|
|实验关联|只选择已注册滑翔机及具体课时/阶段/卡片来源|无关联不自动展示配套实验；自由实验室仍可用|
|关卡与主题图|选默认图或上传自有图，核对站位/桌面/手机|上传不等于绑定保存，见下一节|
|奖励|原课程礼品及勋章管理|本轮不新增规则，课程包也不能导入礼品、金币或成绩|

主题及关卡图片：PNG/JPEG/WebP，单张≤5MiB、≤1600万像素，真实文件头校验。常规资料沿原入口≤50MiB，作品≤100MiB；课堂视频须在对应课时的 MP4/WebM 专用入口上传，单文件≤1.5GB（1,500,000,000 字节，不是1.5GiB）。普通资料中的视频仍受50MiB限制；页面和服务器校验仍是最终约束，课程包使用更小独立限制。资料上传失败保留原引用并重试，不写“成功”占位。

保存与发布区别：文件上传只说明文件已保存，正文/引用需再保存；课程发布控制学生课程可见；课时就绪控制内容开放；卡片发布控制卡片可见。已有学习绑定教材版本，后续人工编辑不覆盖已绑定学生的历史作答/报告。需要更新学生版本时沿原版控流程明确操作，不重建课时规避历史。保存成功但回读失败先重读确认；冲突保留输入，核对服务器修订后再保存。离开未保存表单/上传队列时阅读拦截提示，不把内存草稿误当跨设备保存。

## 3. 四主题、关卡和预览

新课选四项之一，默认校园；存量远航仍可维护，但不能新建/复制/导入voyage。课程“视觉与文案”可任选桌面、平板、手机预览；主题保存到服务器，仅改本课程，不改平台登录/选课/我的外层。

可分别上传封面、桌面背景、手机背景、透明标识。上传后检查预览，再点“保存主题”。移除自定义绑定后回到所选预设；自定义图仍优先，历史文件不批量删除。手机独立构图优先，否则按既有规则居中裁切。

每主题三枚默认关卡：观察、制作、分享。它们是视觉选项，不会生成三节正式课。课时里明确选图，可超过三节复用；默认按顺序建议但可随时换。解析优先级：课时自上传→明确选择的主题默认图→既有安全降级。替换图时保存站位，角色与底图分层，不能把角色烘焙到关卡。地图只按真实课时排序连接相邻节点，不新增通关门槛。

## 4. 制作新题材像素素材

本轮使用 `PBL-new-class/skills/pbl-pixel-course/SKILL.md` 及既有校园参照。先做一个场景和一个节点，按真实网页尺寸/站位检查后再批量。

保持：粗颗粒、阶梯轮廓、少色阶、海军蓝描边、左上光源、统一3/4俯视角、奶油阅读层、寒蝉团圆体、原按钮反馈。可变化：课程内部题材、建筑与植物、地面/天空配色、自有合法图片。不能靠给平滑插画加噪点冒充像素，不能只给旧星海图改色。

每新主题独立封面、桌面场景、手机场景、真透明标识、三枚不同主体透明节点。背景不烘焙文字/路线/按钮，节点保留人物站位空地；平台外壳不改。建议横图1536×1024或16:9、竖图约9:16、节点/标识方形透明；母版保留，本轮发布背景480/960/1536、节点192/384、标识96/192/384无损WebP（整数尺寸舍入≤1像素）。只有响应式缩放，无语义重绘；24母版不可把裁切计为原创。

使用任一实际可用生图工具均需保留提示词、参照、实际工具、模型（不可核实填null）、文件哈希、透明度与用途清单。先看同类参照与网页实际大小再接入；不要伪造工具或转付费接口。本轮母版和生成记录在 `art/`，公共注册表只接受受控键，不拼接请求路径/CSS。

## 5. 课程包

参阅 [完整格式](package-format.md)。下载网页样包及只读预览，都是明确测试材料。脚本在自己的电脑运行以生成/校验包，不能上传脚本给服务器执行。

课程管理“导入课程包”，上传校验后看对象/素材/待补视频→选新建草稿或追加指定课程→生成写入清单→核对目标/数量/不覆盖项→确认→读取服务器结果。新建后明确配置学校及报名；追加只新增课时，不覆盖既有课程介绍、主题、课时、人工文案或历史。导入后继续原位填写、上传、预览和单独发布。

断网或确认回包丢失：先点“查询服务器导入结果”，使用原请求编号恢复；同包版本同目标不会重复导入。目标/学校范围变化需重新生成清单；撤权不能读取原结果继续维护。未确认可恢复本人暂存，24小时过期后下次上传清理；取消只删本次暂存，不删成功课程。更改相同包ID/版本内容会拒绝，应升内容/包版本；不能拿导入器覆盖旧教学。

## 6. 可用定制及开发方案边界

已可用：本课程模块标题/介绍/顺序、空实验入口隐藏、主题/关卡/文章和原位教材编辑。标题留空恢复原人工文案。地图/列表切换及核心组件替换没有实现。

管理员申请处理处可授予/调整/撤销指定mentor×课程的开发方案资格，填用途、审核说明及选填到期时间。导师可查看状态、回复和限制；开发申请对话不自动授资格。资格不开放运行，也不授课程或学校权。[高级开发方案](advanced-development.md)仅设计，任何数据库迁移、平台代码、服务部署仍由审查后的管理员/服务器负责人执行。

## 7. 反馈、申请与通知

学生提交本课程反馈后进入当前管理导师共同池；导师先领取，公开回复与内部协作分开。确需平台协助时手动转管理员并说明；管理员可接管、公开回复或转回导师，学生只见本人公开消息。课程撤回、报名/导师变化后重新核验，管理员兜底，不把他校他课加入导师统计。

学校/课程/开发申请分别进入申请会话；原申请正文、附件、审核结果与对话均保留，公开回复不等于批准。工作台按分类显示完整计数/分页，聚焦、定时或手动刷新核对。通知直达对应对象；失败进入持久补投队列，恢复不会重复兑换/授权/导入。回包丢失先核对结果，不反复新建申请。

会话输入与选中文件只保留当前账号/对象的当前标签页内存，离开有提示；不是跨设备草稿，不保证浏览器退出恢复。新消息/他人更新采用修订核对，附件保存完成会在服务器消息中显示。teacher不能处理反馈/申请，admin可真实代办且审计保留本人身份。
