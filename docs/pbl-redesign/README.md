## 相比原功能的变化

- 登录后进入后台分配的课程选择页；课程内独立管理关卡、实验、成长档案，旧入口保留兼容。平台外层为北航校园像素风，课程内为受控主题
- 关卡整图交互、弯曲不重叠路线、中央详情；课时复用回顾、卡片/练习、报告/评审及独立作品版本流程。十关及前三课模板为当前课程配置，不是所有新课固定数量
- 管理员/负责执行导师在学生同源课时界面原位改教材、上传资料/图片，真实保存；冲突和未保存离开保护，正文与上传队列分别保护。普通教师只读，回放上传仍只管理员
- 账号头像与课程六角色头像分离；姓名旁头像可更换。小智改为无框机器人头部、固定视口可拖动及右下角聊天浮窗
- 独立反思为开放三框，授权教师/导师按既有范围查阅；报告和反馈直接查看，减少重复跳转
- 独立账号徽章陈列室，已获彩色/未获灰度、中央详情及获章反馈；真实课时徽章后端保存，仍以服务端核验原任务条件为准
- 真实金币按账号持久化：原全部任务满足、最新报告通过且有合法0–100整数分时，首次按该分结算一次，后续改分不重复发放
- 签到按服务器北京时间，第1天5枚，此后每天+1，最高10枚，中断重计；真实明细及月历。旧演示兑换余额仍独立，不是正式扣款、库存或发货
- 今日运势按账号/北京日期稳定更新，宜忌各30条；系统文案按ID可审阅改稿，尊重已保存人工改稿
- 后端增加课程范围与对象授权核验、教学维护和头像/反思/徽章/金币数据结构；本提案包含必要后端变更，并非纯样式修改。未修改原仿真源码和物理算法

4. 上线前请确认正式学生名单、教材及参观个人完成依据，进行真实录入/上传/评审/金币/手机实机验收。正式礼品、价格、库存和发放流程尚未接入

## 本地运行与教材边界

依赖安装：仓库根目录、backend、frontend分别 npm ci。开发用 npm run server 与 npm run dev；全新机器需按后端环境示例配置服务，不复制本机密钥或数据

本地持久教学工具见 scripts/teaching.mjs 的命令入口；既有环境仅使用 build:teaching/start，不对实际教学库执行 init/seed/reset。此工具不替代原仓库正式部署方案，本分支也未做生产升级演练

[教材填写操作指南](../lesson-authoring/真实教材录入使用指南.html)随提案提供；逐页文案文件在 docs/**/copy-review，实际显示原稿在 frontend/src/content/uiCopy.jsx。历史图集/截图/日志不随提案打包，请回开发源码仓库查看原轮次记录

第一课公众号图文已在本机教学库录入（8段、284字符、9个图片位置）；运营数据库、原照片、上传附件、Key及备份不在PR内，上线时需单独受控迁移，代码拉取不等于已导入这些内容
