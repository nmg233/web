# 本轮接入规格

基线2296311，开始时工作区干净。原仓库只读，唯一推送目标shrrrrrrrr/web-frontend-test。

学生与维护端共用课时展示层；维护模式仅注入区域编辑、附件队列和只读学习占位，不调用学生完成、作答、报告、奖励接口。三个模板和四个阶段同源。正文使用结构化段落/图片块，React文本输出，无HTML执行、iframe或外部图片地址；图片引用必须属于同一课程及课时的真实图片资源。

兼容迁移023给lessons追加review_content/report_guidance/experiment_guidance及article_blocks；旧description继续作课时说明及回顾正文回退。空字段保留旧显示。文章随lesson同一revision保存，维护端始终传已知revision，保留旧调用方可选策略；SQLite同步路由校验及写入不跨await。原知识卡/练习revision和真实上传upload_token继续使用。

保存即写入当前教材，没有独立整课草稿版本；内容就绪和课程发布独立维护，不自动切换。已发布且可访问的课程保存后，学生下次读取可见；卡片仍按draft/published。学习状态不因编辑或文章阅读伪造完成。

实际教学预检后只停止对应教学服务，一致备份数据库/附件/私有配置。先在隔离副本验证22→23、重复执行、旧字段/附件、完整性及恢复，失败停止实际接入。正式库仅授权第一课图文导入；目标由明确命令参数和实际课程/课时核对，工具不猜标题，导入带源hash和目标revision冲突检查，重复导入无新附件。原材料及九张图片留本地交接目录，不进Git；截图若有真实照片也仅留本地验收目录。

回退代码不等于回退数据库。新增列兼容旧代码；有新教材或账本后不得旧库覆盖。恢复演练只到新的独立目录，必要时保留新库前向修复。DDL预计毫秒级，备份/重启有短暂停机，无生产部署或隧道切换。
