# 课程授权、学校审批与学生建号操作指南

## 管理员授予课程管理

1. 登录管理员，进入“课程管理”。已有课程可点“管理授权”；新建课程成功后进入“学员与授权”。
2. 在“课程管理授权”查看现有关系；旧关系来源为 `legacy_creator`、`legacy_instructor`，新自建关系为 `creator`。
3. 选择有效导师，操作选择“授予课程管理权限”，填写原因，点“保存课程授权”。可逐个授权多位导师。
4. 成功提示表示服务端已保存。下表显示授权人、时间、关系来源；展开审计可核对每次变更。
5. 移交创建导师的管理职责时，先授权接任导师，再撤销原导师；不需要更改历史创建者或课程授课人。
6. 撤销选择相应导师，操作选“撤销课程管理权限”，填写原因再保存。旧会话的下一请求立即受限；账号、课程、学生和历史教材不删除。

409 表示其他管理员已修改授权；当前输入保留。点“核对最新授权”，确认表格状态和修订后再保存。网络响应不明时保持原输入和请求编号重试，或先读取核对，不重复建立关系。

## 导师维护获授权课程

“课程管理”只列本人已获管理权的课程。六页签与管理员使用同一教材和上传入口；视频简介必填，回放支持 MP4/WebM，资源/图片继续沿用第 1 步限制。上传、保存正文、发布卡片、课时就绪分别生效，不能互相代替。

“视觉主题与学生预览 → 打开本课程学生效果与原位文字编辑”保留导师身份，只允许课程及课时范围保存系统文案和真实教材；不开放平台全局文案，也不模拟真实学生提交/作答/兑换。切换其他课程请返回课程列表进入对应工作区。

“学员与授权”可导入合法负责学生和本人授权课程相关学生，不能搜索/导入全平台无关学生。新建学生默认关联创建导师，因此可在所管课程中报名。异常移除报名须说明原因，已有学习历史仍被拒绝。

若权限被撤销，页面清除课程私有内容，保留本人亲自输入文字的导出入口。导出后交由本人私有保存，恢复授权后重新检查并人工核对填写；不自动覆盖服务器，也不把附件选择当成已上传。

## 导师申请学校

1. 导师侧栏进入“账号与组织”，点“申请新建学校”。
2. 填学校名称、地区、申请说明；联系人、联系方式按需填写。不要填写与学校审批无关的学生身份资料。
3. 点保存，查看待审核状态。网络失败时弹窗和输入保留，保持原内容重试；同名待审核申请不能重复建立。
4. 申请列表可按状态筛选，查看审核人、时间、驳回理由及当前学校管理状态。批准申请不等于获课程管理权。

## 管理员审批与撤销学校管理

1. 固定窗口：“账号与组织 → 学校申请审核”；也可从工作台“待审学校申请”和站内通知直接进入指定申请。
2. 查看申请人、地区、说明及联系方式。选择批准或驳回；驳回必须说明原因。
3. 没有同名学校时，批准在事务内新建学校和导师管理关系。
4. 有同名学校时不会自动创建或接管：先线下核对关系，选择准确的现有学校 ID/地区，勾选明确授权确认，填写核对原因后才能批准。已有学校停用时不能关联，交由原全局管理员流程处理。
5. 结果失败/409时保留输入。“核对最新修订（保留输入）”只采用尚待审核对象的新修订，不自动保存；若已被别人处理，查看结果后关闭，不再重复审批。
6. 学校管理表可单独“撤销学校管理”，填写原因。撤销立即阻止旧会话建班/建号和交付凭据，已有学生与教学数据保留。不会顺带撤销其他独立课程授权。

## 获准学校建班与学生账号

1. 导师在“账号与组织”的“获准学校”选择学校，界面明确显示学校 ID。未批准或撤销的学校不能建班建号。
2. “新建本校班级”，填写班级名称和年级。相同学校的相同班级不会重复建立。
3. “新建本校学生”，选择本校班级、填写姓名；登录账号可选填，留空沿用原学校代码/学生姓名/序号规则。角色固定为 student。
4. 保存成功后点“读取本次创建的有效初始凭据”，在私有弹窗核对账号和初始密码，并私下交给本人。凭据不会写到通知、日志、公开文件或幂等结果里。
5. 仅能交付本人在该校创建、仍有效且未改密/重置的学生初始凭据；改密后不能再次导出。需恢复账号时联系管理员走原重置流程。
6. 进入自己获授权课程，选择该学生报名。新学生第一次登录必须改密，改密前业务 API 拒绝；改密成功后进入已获配课程。未分配课程显示原空状态。

导师不因此获得全平台学校、学生迁移/删除、角色修改、批量建号、教师/admin/mentor 建号权限。管理员原批次导入、失败恢复、凭据交付和学校迁移入口继续保留。
