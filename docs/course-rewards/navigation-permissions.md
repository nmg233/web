# 五模块功能迁移表与权限

|旧入口/能力|最终位置|保留的业务|
|---|---|---|
|工作台待办、评审、发放、申请|工作台|按真实对象跳转，订单携带课程，未归属兼容旧链接|
|课程列表、新建、基础信息|课程管理→课程概览|真实标题、目标、发布/归档|
|课时、文章、卡片题目、任务|课程→课时与内容|同一编辑与存储、教材版本冻结；JSON仅高级工具|
|资源、回放|课时与内容/课程共享资料|课时与共享范围区分、文件历史保护|
|报名、管理授权|课程→学员与授权|仅admin可授权/撤销；异常移除保护历史|
|背景、封面、手机、标识、原位预览|课程→视觉主题与学生预览|上传与保存绑定分开；教材与系统文案分开|
|勋章、原奖励管理|课程→课程奖励|勋章可选、课程礼品、库存、订单、发放和通知恢复|
|归属未知旧礼品/订单|课程管理中存量核对链接、课程奖励底部兼容入口|admin独占、不猜课程、不加第六个一级菜单|
|作品、报告评审、成长观察|教学与成长|权限、历史版本、反思、反馈保持|
|账号、学校班级、导入、学校申请|账号与组织|admin全局，导师仅获准学校内建班建学生|
|系统文案、反馈、AI、工具|平台设置|原权限和AI启用状态保持|
|学生金币、签到、墙和兑换|我的；课程内带筛选入口|账号统一金币，课程区分可兑/未获，历史保留|

|奖励操作|admin|显式授权academic_mentor|其他mentor/teacher/学生|
|---|---|---|---|
|礼品、图片、库存/上下架|所有课程|仅所管课程|拒绝写入|
|通关开关、课时勋章/图案|所有课程|仅所管课程|拒绝写入|
|订单列表/详情、发放|所有课程|仅所管课程，撤回后仍可履约|拒绝|
|未归属旧礼品、图片和订单核对/绑定|允许，依据/版本/审计|拒绝|拒绝|
|奖励通知查看、手动补发|对应课程或未归属|仅对应课程|拒绝|
|个人金币、签到、兑换|工作人员无个人资格|工作人员无个人资格|仅当前有效学生自己的账号|
|未获章/可兑礼品及图片|管理/预览|对应课程管理/预览|学生仅有效报名+课程发布，teacher无兑换资格|
|历史获章/订单/历史图片|管理范围内|管理范围内|学生仅本人；不授予失效课程教材权限|

唯一管理依据是1030的course_managers，未恢复created_by/instructor_id隐式权限。列表、图片、指定对象、发放和补发均由后端重验；前端筛选不承担授权。撤销后原令牌下一次请求即拒绝，附件404依旧局部处理。
