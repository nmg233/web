# 权限、版本及迁移说明

## 权限与学习流程

知识卡片及配套练习写入沿用最新上游的管理员权限；导师可预览，并继续维护自己有权管理的课时安排、文章、附件及评审。教材指南中的导师卡题编辑描述为旧版本行为，应以此处和当前页面权限提示为准。课堂回放的上传、修改、删除仅限管理员；学生、教师与导师按授权查看。

访问 `visit` 或 `preparing` 课时返回只读材料，不绑定版本、不生成学习进度、不允许作答或提交。正常学习课时保留上游内容就绪检查、依次作答、次数、报告历史和补学规则。课时顺序不新增跨课时门槛。

课程有学习历史后不能撤回为草稿；合法归档、取消报名及账号停用仍执行授权失效。存在未完成补学时不能结课。课时金币按学生绑定教材版本、最新有效报告及既有作品条件核验，仍只按原规则首次结算，修改分数不会重复发币。

账号有金币、签到、兑换或徽章历史时不能物理删除或变更角色；预检和实际写事务内均重验，避免并发窗口内级联删除资产历史。正常停用、归档入口保留。

## 教材历史和附件

新版本快照包含原有完整课时字段、文章和资源元数据，学生已绑定版本不会因管理员后续改稿而切换正文；安排和授权状态仍实时核验。

旧快照缺少本项目文章等字段时，`1025` 将升级时仍可确认的字段保存在独立 `lesson_version_supplements` 表，**不重写原快照 JSON**。仅关联原快照已有资源 ID，资源响应不泄露磁盘路径或上传令牌。接口明确标记 `legacy_lesson_fields` 和 `supplement_source: upgrade`；这部分是升级时兼容补充，不能冒充已不可追溯的历史原稿。

教材快照、补充表和文章仍引用的附件/回放不能删除；未被历史引用的文件可按原权限清理。资源 ID 与回放 ID 分开检查，避免不同表同号误锁定。

## 迁移身份与数据保护

上游已发布的 `001–020` SQL 文件及编号保持原样。本项目旧 `016–023` 经名称和结构签名核验后映射为 `1016–1023`，原 `applied_at` 保留，原身份记录于 `migration_identity_history`。`1024` 为真实兑换，`1025` 为旧教材快照补充。最终 30 条迁移记录。

整个升级使用即时事务。未知同号异义或已知记录与结构不符时拒绝并回滚，不清空迁移历史、不重建数据库、不重复发币。空库 schema 已含上游 `001–020` 与本地 `1016–1023`，仅实际执行后续迁移；旧库按各自记录补齐缺少的结构。旧 `014` 回放摘要兼容在本地旧身份桥接之后执行，避免误认本地 `016`。

原报名结课时间不因升级被重新计算。仅为已有非空结课时间且缺少封存清单的报名补充可核实的完成课时；不将未完成报名改为完成，不声称升级清单等同于不可追溯的原始历史。

通知通用 worker 与奖励 worker 共用持久去重和原子投递标记。奖励的管理员目标在发送时解析；无有效管理员时保留失败任务供恢复。通知失败不会重新扣币、扣库存或创建订单。

## 备份与回退

本轮先备份实际环境至私有 `.local/teaching-before-upstream-merge-20261012`，数据库一致性备份及上传、反馈、配置一并保存。升级和浏览器写入均使用隔离副本/合成库，未向正式教学库录入验收礼品。

隔离验证包含当前教学旧库、上游最新结构构造的合成旧库、空库、重复迁移及真实 restore 工具恢复。没有获得上游生产数据库。原环境有一个既存缺失附件引用，保留记录而不伪造文件。

回退必须停服，并核对升级后新增订单与教材数据；旧代码不认识兑换支出，不能直接连接新库。应使用一致性备份恢复到独立目录验证后再受控切换。Linux 生产安装、真实外部模型和公网部署不在本次实际验收范围。
