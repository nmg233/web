## 目的与行为

提交 PBL 像素课程空间、教材可视化维护与真实礼品兑换，供原项目复核。本分支已实际合入 `main@681328d`，保留上游教材版本绑定、报告历史/补学、账号批次与组织转移、通知 outbox、健康检查和部署备份工具、三维回放。

只更新本人 fork 的提案分支，不直接推送或合并原仓库 main，不切换公网。运营数据库、真实学生数据、私有附件、密钥和备份不进入提交。

## 主要变化

- 学生在后台授予的课程中学习，课程空间独立组织地图、教材、实验和成长档案，保留旧链接及其他角色入口。沿用像素画风和人工文案。
- 可视化原位填写、上传与保存教材，保留 revision 校验、防丢稿和上传队列恢复。知识卡片/练习仅管理员维护；导师按授权维护文章和附件并评审，教师只读。参观/准备中材料只读。
- 学生绑定的教材、原作答及报告历史保留，开放反思和补学可用。金币仍按既有签到及课时规则真实结算，不因改分重复发放。
- 管理员奖励管理支持礼品名称、实物/徽章、介绍、一张真实图片、金币价格、库存、限兑、上下架和学生预览；管理兑换记录并在线下发放后记录操作人/时间，通知学生。
- 学生用现有真实金币兑换。事务内检查余额、库存及限兑，原子扣币、扣库存、建订单/授予徽章；支持请求幂等、双进程并发、丢响应恢复和跨设备查询。通知失败可重试，不重复兑换。
- 正式入口不再使用演示余额/兑换，旧演示数据独立保留；真实礼品无预置，由管理员录入。账号资产历史受删除/角色变更保护。
