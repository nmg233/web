## 3. 隔离浏览器验收

使用 computer-use 技能在本机回环地址操作自建隔离夹具，不访问公网测试站或真实用户账号。浏览器测试直接发现并推动修复了账户菜单仅 hover 的操作问题及状态/答案展示的可读性问题。

夹具命令（两个终端，在项目根目录）：

```powershell
node scripts/ui-qa-server.js --isolated
node frontend/node_modules/vite/bin/vite.js --config scripts/ui-qa-vite.config.mjs
```

默认 API 为127.0.0.1:3091，前端127.0.0.1:5188。数据库与公开/私有上传都在系统临时目录，正常终止时尝试清理自己的临时数据；强制终止可能残留临时目录，须核对确切夹具路径再清理，不能递归清理整个Temp。本次组织专项临时服务和浏览器已停止，临时目录清理受工具策略限制而保留，不影响业务库；既有业务数据不参与。源码中的 qa_* 账号和固定密码仅为回环验收夹具，不是正式初始账号；不得将此服务用于正式部署。

实际完成：

1. 学生课后任务按两课时显示：完整课时进入学习总界面；缺内容课时禁止开始；独立成果另有入口。
2. 课堂回顾显示视频容器、简介、资料下载入口，以“我已完成”推进。
3. 五题型实际提交：单选故意答错，其余客观题答对，简答采用不同表达。答错仍有详解，简答不判错。
4. 刷新后五道本人答案仍在、输入与提交锁定；完成卡片显示客观题75分而非100分。
5. 学生报告与反思提交后第三阶段完成，等待评审85%。导师能看到逐题题干/选项/本人答案/参考/详解，并保存反馈。
6. 导师60分退回；学生从“根据意见修改”回到第三阶段，前两阶段保持，逐题反馈可见且不能重答。
7. 学生补应用设想重提第2版；导师队列仅最新第2版。导师95分通过，课时100%，旧退回第1版在详情历史保留。
8. 普通教师只读查看两名负责学生；已完成课时100%、未开始课时0%、课程50%，卡片5/5作答、75分。菜单不提供教学编辑。
9. 管理员进入内容编排，看到缺项清单，打开学生视角本地预览并模拟答题；前后核对隔离数据库均为5条作答、1条学生版本绑定，预览不写学习记录。
10. 补充组织专项使用重启后的独立夹具：原教师归属班级提示非学生账号，确认按钮禁用；另一个仅含两名学生的班级选目标学校/同校教师/原因成功迁移，原学校人数和班级数更新且未自动跳页；进入目标学校，展开迁移历史可见原因、操作者、两名学生原账号及导师。

证据截图保存于本机临时目录：`pbl-course-loop-2026-10-08.png`（答案锁定与逐题反馈）、`pbl-report-approved-2026-10-08.png`（第二版通过与旧版历史）、`pbl-class-transfer-2026-10-08.png`（迁移历史与原负责关系）。截图是隔离测试数据，不是生产学生证据；临时目录可被系统清理，不作为长期归档。

视频夹具仅有文件头，不具备实际可播放编码，因此**没有验收真实播放、长播放、续签拖动或弱网**。看到错误恢复入口不能算视频播放通过。浏览器服务启动后加载的后端模块不会热更新；末尾补充的公共视频门禁/只读边界以最终自动测试为证，未冒充再次浏览器验收。

- 公开上传与私有附件分别备份，私有归档真实读回验证；数据库脚本支持引号路径/空格并安全保留七份。本轮没有实际生产数据库恢复。
- 自动回滚只恢复代码链接，不覆盖数据；旧代码对新业务语义保护不足，恢复链接后仍应限制写入、人工评估。详见 [部署与恢复](部署与恢复.md)。

1. 组织迁移已通过本地 UI/API 验收；上线前仍应在实际历史数据副本核对班级/学校不一致记录及原教师归属。遇到冲突先处理，不静默清空负责关系绕过保护。

4. 独立成果完整附件提交/退回/重提/通过的浏览器闭环；当前自动服务/HTTP回归覆盖，不等于真人操作路径全部验收。
5. Linux指定Python、C++/glibc原生模块、systemd/Nginx/current配置、健康失败恢复；隔离复制数据库与两类附件并校验、启动和鉴权，记录恢复时间及数据损失窗口。
6. 生产HTTPS、JWT/配置权限、外网暴露、上传与私有附件鉴权、磁盘与outbox告警、异地备份、解析进程OS级资源限制及负载容量另行审查。
