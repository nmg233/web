## 旧入口与能力 → 新位置（实现前盘点）

|原入口/隐藏能力|新位置|兼容原则|
|---|---|---|
|工作台统计、最新作品、提醒|工作台|报告、礼品、反馈直接打开真实对象|
|工作台学校、新建学校、学校详情/班级|账号与组织 · 学校与班级|仍使用原学校页面；学校申请第 2 步|
|账号列表、状态、改密、导入、凭据、分配、迁移记录|账号与组织 · 账号管理|保留原账号页面内弹窗/批次和详情深链接|
|课程列表、新建/编辑、发布/撤回/归档/删除|课程管理 · 课程概览|原生命周期和阻止关闭规则不变|
|教材维护、课时编辑、文章上传、知识卡片/习题|课程管理 · 课时与内容|统一沿用 TeachingPreview / InlineTeachingEditor / LessonContentEditor|
|课程资源、文件下载、AI 索引|课程管理 · 课程共享资料|课时文件在课时内自动绑定；旧资源均可访问|
|课程学生导入/移除|课程管理 · 学员与授权|现有报名权限不变，课程授权第 2 步|
|课时图、站位、章节、计划节点、实验关联|课程管理 · 课时与内容|存量十关保留，只有新课程启用自动地图|
|学生文字编辑、文章/教材预览、历史版本、JSON 高级工具|视觉主题与学生预览 / 平台设置 · 公共文字|沿用同一编辑器、真实对象与存储，保留 /student-copy、/copy-review|
|报告评审、作品版本、逐题反馈、学生档案、观察评价|教学与成长|直接进入所选报告/作品/学生，旧深链接不重定向丢对象|
|礼品管理、兑换发放、通知重试|课程奖励 · 存量奖励，待关联课程|继续真实管理，不迁移礼品归属；课程奖励第 3 步|
|AI 设置、AI 测试、管理员实验、反馈|平台设置|不改变 AI 启用状态，不新增工作人员兑换资格|
|通知、个人账号、密码、退出|顶部|原对象链接保持可用|
