# 星海远航：课程与地图交付包

本包补齐“代码已经部署，但本机星海课程及配置没有迁到服务器”的交接。包含维护原稿的课程清单、独立导入工具及操作说明，不包含运营数据库、账号、学生学习记录、密钥或实拍图片。

- `course.json`：远航主题、三节现有课时、十个地图槽位、第一课8段文字/9张图片引用、1条滑翔机关联、3个课时徽章定义。
- `import-course.cjs`：默认仅预检；显式 `--apply` 才创建课程，自动一致性备份、事务写入、ID重映射和幂等记录。
- [完整管理员交接指南](../../docs/course-handoff/管理员交接指南.md)：私有附件、导入、预览、发布、分配、AI启用和回退。

当前三课时保持 `preparing`，后七关保持未配置。没有新增知识卡片、习题、作品任务或视频；不将占位内容冒充已齐备的正式教材。导入后课程为**草稿**，不自动发布、不报名、不发币/徽章，不修改其他课程。

## 先收齐私有图片

九张教学实拍图片通过单独的私有附件包交接，不进入公开Git。解压后应获得 `private-assets/image-01.jpg` 至 `image-09.jpg` 和清单。导入器核对每张图片大小、SHA256和文件签名；缺失/被替换时拒绝，不伪造成功。请通过受控文件传输交给服务器管理员，勿放入网站公开目录或PR附件。

## 预检与实际导入

服务器已按既有部署流程完成数据库迁移并安装 `backend` 依赖。先核对数据库及上传目录，停止写入或安排维护窗口，联合备份数据库、uploads和私有附件。

```bash
node content/star-voyage/import-course.cjs \
  --db /实际路径/database/pbl_platform.db \
  --uploads /实际路径/uploads \
  --assets /私有交接目录/private-assets \
  --admin-username '<有效且已改密的管理员用户名>'
```

默认预检不写库、不创建附件或备份。确认输出的课时/槽位/文件数量后，在同一命令最后增加 `--apply`。路径和管理员均必须使用目标环境真实值；可以用 `--admin-id` 代替用户名，不需要导入脚本保存账号密码。

工具不会初始化空库或运行迁移。同名课程已存在时拒绝猜测合并；既有教学/作品/报名/奖励数据不被删除。新ID由目标库生成，图片、课时、地图和实验引用整体重映射，不硬编码本机9003等ID。

同包再次执行通过既有 `request_results` 返回原ID，**不覆盖导入后改稿**；跨管理员重试也不重复建课。包内容不同但身份相同则拒绝，应使用现有教材维护修改课程，不能修改清单后强行覆盖。

## 后续必须人工完成

管理员用导入结果的 `courseId` 打开 `/courses/<courseId>`，预览文字和九张图片，核对远航主题/十关及准备状态，再显式发布课程、按现有后台分配学生。学生进入该课程后才会看到远航地图；其他校园课程保持原样。

AI机器人和问答代码已存在；真实模型密钥及 `AI_CONFIG_SECRET` 必须在服务器/管理员设置中单独配置。课程包不会启用模型、生成密钥或替代回答质量验收。
